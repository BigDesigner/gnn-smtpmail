# AI Agent Directives and Rules

This document outlines the strict communication style and coding boundaries for AI agents working in this workspace.

## 1. Communication Style
- **No Fluff:** Completely omit introduction sentences, greetings, apologies, congratulations, and politeness templates.
- **Direct Focus:** Focus directly on outputting production-ready code, error-free command lines, and raw analysis reports.
- **Error Handling:** When an error is made, do not apologize. Acknowledge the error and directly output the corrected code, command, or file replacement.

## 2. Coding and Quality Directives
- **Zero-Conflict CSS:** Always use inherited styles and relative measurements. Avoid absolute positioning or hardcoded dark/light colors.
- **Safe-by-Default PHP:** Never use unescaped print statements or raw SQL query strings.
- **Preserve Comments:** Do not delete or modify code comments or docstrings from core files.
- **Pre-commit Audit:** Always review prefixing, sanitization, capabilities, nonces, and prepared SQL patterns before staging code changes.
